## 🧱 Кирпичик 2: Разрез числа на цифры (Цикл while)

Прежде чем переводить число, его нужно разложить на отдельные цифры в массив. Например, число `3954` должно превратиться в массив `[3, 9, 5, 4]`.

    int temp = num;
    int i = 3; // Индекс последней ячейки массива (единицы)

    while (temp > 0 && i >= 0)
    {
        // ТВОЙ КОД ЗДЕСЬ:
        // 1. Положи в digits[i] последнюю цифру числа temp
        // 2. Уменьши temp в 10 раз
