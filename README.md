# Полное руководство: Перевод арабских чисел в римские (IntToRoman)

Этот гайд создан для того, чтобы разложить один из самых красивых алгоритмов на простые кирпичики. Мы разберем логику задачи, изучим код строка за строкой и детально разберем полезную фишку C# — тернарный оператор.

---

## 📋 1. Описание задачи и ограничения

**Суть задачи:** Нам дано привычное целое арабское число **num** (например, `3075`). Наша цель — превратить его в строку, состоящую из римских символов (`MMMLXXV`).

### Ограничения: $1 \le \text{num} \le 3999$
Почему именно такие границы?
* **Нижняя граница (1):** В римской системе счисления принципиально **нет нуля** и отрицательных чисел. Самое маленькое число — это `I` (один).
* **Верхняя граница (3999):** Римские цифры строятся на базе семи символов: `I`(1), `V`(5), `X`(10), `L`(50), `C`(100), `D`(500), `M`(1000). Чтобы написать 4000, нам понадобился бы следующий символ (для 5000), которого в стандартном латинском алфавите для этих целей нет. Максимум, что мы можем выжать из символа `M` (тысяча) без нарушения правил — это написать его три раза подряд (`MMM` = 3000) и добавить к нему 999 (`CMXCIX`). Итого: 3999.

---

## 💻 2. Исходный код решения

Вот готовый метод на C#, который решает эту задачу максимально эффективно:

```csharp
using System;
using System.Text;

public class RomanConverter 
{
    public string IntToRoman(int num) 
    {
        // Базовые массивы-карты для синхронизации разрядов
        // Индексы:              0    1    2    3
        var ones = new string[]{ "M", "C", "X", "I"}; 
        var fives = new string[] {"", "D", "L", "V"}; 

        var digits = new int[4];
        var temp = num;
        var i = 3;

        // Распиливаем число на отдельные цифры
        while(temp > 0 && i >= 0)
        {
            digits[i--] = temp % 10;
            temp /= 10;
        }

        var digitsCount = 3 - i;                
        var sb = new StringBuilder();
        
        // Главный цикл сборки римской строки
        for(int j = 4 - digitsCount; j <= 3; j++)
        {
            var digit = digits[j];

            if(digit == 0)
                continue;

            if(digit == 4)
            {               
                sb.Append(ones[j]); 
                sb.Append(fives[j]);
            }
            else if(digit == 9)
            {                
                sb.Append(ones[j]); 
                sb.Append(ones[j - 1]);
            }
            else
            {
                // Место работы тернарного оператора
                var count = digit >= 5 ? digit - 5 : digit;

                if(digit >= 5)
                    sb.Append(fives[j]);

                for(int k = 0; k < count; k++)
                    sb.Append(ones[j]);
            }
        }

        return sb.ToString();
    }
}
```

## ⚙️ 3. Подробный разбор

Вместо того чтобы писать километры условий `if/else` для сотен, десятков и единиц по отдельности, автор кода заметил **гениальную математическую закономерность**:

> Принцип лепки цифр `4`, `9`, `7` или `3` абсолютно одинаков на любом разряде! Меняются только буквы.

* `4` единицы — это `IV` (1 перед 5)
* `4` десятка — это `XL` (10 перед 50)
* `4` сотни — это `CD` (100 перед 500)

Поэтому автор создал две "карты" (массивы `ones` и `fives`), где буквы жестко привязаны к своим индексам-разрядам:
* Индекс `0` (Тысячи): единица = `M`. Пятерки нет.
* Индекс `1` (Сотни): единица = `C` (100), пятерка = `D` (500).
* Индекс `2` (Десятки): единица = `X` (10), пятерка = `L` (50).
* Индекс `3` (Единицы): единица = `I` (1), пятерка = `V` (5).

---

### Трассировка кода на примере числа `3075`

#### Этап А: Распиливаем число на цифры
```csharp
var digits = new int[4]; // Создаем массив из 4 пустых ячеек: [0, 0, 0, 0]
var temp = num;          // Запоминаем temp = 3075
var i = 3;               // Будем заполнять массив с самого конца (с единиц)
```
Запускается цикл `while`. Он «откусывает» от числа по одной цифре с помощью `% 10` (остаток от деления) и уменьшает число через `/= 10` (деление нацело):
1. **Шаг 1:** `3075 % 10 = 5`. Кладем в `digits[3] = 5`. Число `temp` становится `307`. Индекс `i` уменьшается до `2`.
2. **Шаг 2:** `307 % 10 = 7`. Кладем в `digits[2] = 7`. Число `temp` становится `30`. Индекс `i` уменьшается до `1`.
3. **Шаг 3:** `30 % 10 = 0`. Кладем в `digits[1] = 0`. Число `temp` становится `3`. Индекс `i` уменьшается до `0`.
4. **Шаг 4:** `3 % 10 = 3`. Кладем в `digits[0] = 3`. Число `temp` становится `0`. Цикл завершен!

В итоге наш массив `digits` выглядит так: `[3, 0, 7, 5]`. Переменная `i` остановилась на отметке `-1`.
```csharp
var digitsCount = 3 - i; // 3 - (-1) = 4. Наше число состоит из 4 значащих цифр.
var sb = new StringBuilder(); // "Продвинутый" инструмент для сборки текста без лишнего мусора в памяти.
```

---

#### Этап Б: Собираем римские символы (Главный цикл)
Мы начинаем бежать по нашему массиву `[3, 0, 7, 5]` слева направо. Цикл стартует с индекса `4 - 4 = 0`.

**1. Индекс `j = 0` (Тысячи). Цифра `digit = 3`.**
* Проверки на 0, 4 и 9 не срабатывают. Программа падает в блок `else` (обычная лепка).
* Число 3 меньше 5, значит, мы просто рисуем «единицу» этого разряда (`ones[0]` = `M`) три раза подряд.
* *Строка в памяти:* `MMM`

**2. Индекс `j = 1` (Сотни). Цифра `digit = 0`.**
* Срабатывает самое первое условие: `if(digit == 0) continue;`
* Программа мгновенно бросает этот шаг и переходит к следующему разряду.
* *Строка в памяти:* `MMM` (сотни просто пропущены).

**3. Индекс `j = 2` (Десятки). Цифра `digit = 7`.**
* Проверки на 4 и 9 снова мимо. Программа заходит в блок `else`. И вот тут мы спотыкаемся о...

## 🛠 4. Разбор тернарного оператора

Внутри блока `else` нас встречает вот эта строчка:
```csharp
var count = digit >= 5 ? digit - 5 : digit;
```

**Тернарный оператор `?:`** — это компактный гибрид условий `if` и `else`. Он называется "тернарным" (трехместным), потому что в нем всегда участвуют три элемента.

### Как читать эту строчку человеческим языком:
> *"Посмотри на условие `digit >= 5`. Если это **правда (True)**, то выполни математику **после знака вопроса** (`digit - 5`) и запиши результат в переменную `count`. А если это **ложь (False)**, то выполни то, что стоит **после двоеточия** (просто возьми `digit`) и запиши это в `count`".*

### Карта-схема:
` Условие ? Выражение_если_True : Выражение_если_False ; `

### Прямое соотношение с обычным `if-else`:
Если переписать эту строчку кода классическим (длинным) путем, она превратится в следующий массивный блок:
```csharp
int count; // Создаем переменную заранее

if (digit >= 5) 
{
    count = digit - 5; // Если цифра 7, то 7 - 5 = 2
}
else 
{
    count = digit;     // Если цифра была бы 3, то count = 3
}
```
Тернарный оператор позволяет сократить эти 9 строк кода до одной аккуратной строчки!

### Зачем это нужно алгоритму?
В римской системе цифры больше пяти (например, 7) собираются из основы `5` (буква `V` для десятков) и «хвоста» из единиц (две буквы `I`). 
Тернарный оператор как раз вычисляет длину этого «хвоста»: 
* Для цифры `7`: условие `7 >= 5` верно -> `count = 7 - 5 = 2` (сначала вписать V, а потом дописать две единицы).
* Для цифры `3`: условие `3 >= 5` неверно -> `count = 3` (просто написать три единицы).

---

### Продолжение трассировки для `3075` (Индекс `j = 2`)
* Наш тернарный оператор посчитал `count = 2`.
* Следующая строка: `if(digit >= 5) sb.Append(fives[j]);` — так как 7 больше 5, мы печатаем «пятерку» десятков (`fives[2]` = `L`).
* Дальше запускается мелкий цикл `for`, который выполняется `count` (2) раза и дописывает «единицы» десятков (`ones[2]` = `X`).
* *Строка в памяти:* `MMM` + `L` + `XX` = `MMMLXX`

**4. Индекс `j = 3` (Единицы). Цифра `digit = 5`.**
* Программа снова падает в блок `else`.
* Тернарный оператор: `5 >= 5` — это `true`. Считаем: `5 - 5 = 0`. Значит `count = 0`.
* Условие `if(digit >= 5)` срабатывает и печатает «пятерку» единиц (`fives[3]` = `V`).
* Цикл `for` не выполняется ни разу, так как `count == 0` (дописывать палочки не нужно).
* *Строка в памяти:* `MMMLXX` + `V` = `MMMLXXV`

Метод завершает работу и возвращает итоговую строку: **`MMMLXXV`**.

---

## 🏁 5. Резюме

1. **Красота архитектуры:** Алгоритм изящен за счет синхронизации двух массивов (`ones` и `fives`). Программа не думает о разрядах, она просто двигает индекс `j` от 0 до 3.
2. **Особые случаи:** Цифры `4` и `9` обрабатываются отдельно в `if/else`, потому что они используют правило вычитания (младшая цифра пишется *перед* старшей).
3. **Тернарный оператор** — это не магия, а просто синтаксический сахар. Он идеально подходит для коротких ветвлений, когда нужно мгновенно выбрать одно из двух значений на основе условия и сразу записать его в переменную.

# Трассировка алгоритма IntToRoman на примере числа 3954

Давай закрепим пройденный материал и пошагово «прокрутим» внутри нашего алгоритма число **`3954`**. На нем мы увидим работу всех возможных сценариев: и обычную лепку через тернарный оператор, и особый случай с девяткой, и особый случай с четверкой.

---

## 📋 1. Разберем на примере другого числа. Освежим в памяти карту символов
Перед стартом вспомним наши массивы-ориентиры:
* **Индекс `0` (Тысячи):** `ones[0]` = **M**
* **Индекс `1` (Сотни):** `ones[1]` = **C**, `fives[1]` = **D**
* **Индекс `2` (Десятки):** `ones[2]` = **X**, `fives[2]` = **L**
* **Индекс `3` (Единицы):** `ones[3]` = **I**, `fives[3]` = **V**

---

## ⚙️ 2. Пошаговая трассировка числа 3954

### Этап А: Распиливаем число на цифры
После работы цикла `while` наше число `3954` разбивается на индивидуальные цифры и попадает в массив `digits`.

* Наш массив `digits` теперь выглядит так: `[3, 9, 5, 4]`.
* Длина числа (`digitsCount`) равна `4`.
* Главный цикл `for` стартует с индекса `j = 0` и побежит до `3`.

---

### Этап Б: Главный цикл сборки (Разряд за разрядом)

#### 1. Индекс `j = 0` (Тысячи). Цифра `digit = 3`
* Проверки на `0`, `4` и `9` не срабатывают. Программа заходит в блок `else`.
* **Работает тернарный оператор:** `3 >= 5 ?` — это **Ложь**. Значит, тернарник выбирает выражение после двоеточия. Переменная `count` становится равной `3`.
* Условие `if(digit >= 5)` не срабатывает (буква `fives` не пишется).
* Цикл `for` выполняется `3` раза и дописывает `ones[0]` (букву **M**).
* *Строка на данном шаге:* **`MMM`**

#### 2. Индекс `j = 1` (Сотни). Цифра `digit = 9`
* Срабатывает условие `else if(digit == 9)`. Это наш особый случай — правило вычитания!
* Код выполняет две строчки:
  ```csharp
  sb.Append(ones[1]);     // Печатает "ones" текущего разряда сотен -> "C"
  sb.Append(ones[1 - 1]); // Печатает "ones" предыдущего разряда (тысяч) -> "M"
  ```
* В строку склеивается комбинация **CM** (сто перед тысячью, то есть 900).
* *Строка на данном шаге:* `MMM` + `CM` = **`MMMCM`**

#### 3. Индекс `j = 2` (Десятки). Цифра `digit = 5`
* Проверки на `0`, `4` и `9` идут мимо. Программа прыгает в блок `else`.
* **Работает тернарный оператор:** `5 >= 5 ?` — это **Правда**! Тернарник выбирает выражение до двоеточия (`digit - 5`). Считаем: `5 - 5 = 0`. Переменная `count` становится равной `0`.
* Условие `if(digit >= 5)` срабатывает (ведь 5 $\ge$ 5). Код печатает `fives[2]` (букву **L**).
* Цикл `for` должен выполниться `count` раз. Так как `count == 0`, цикл не делает ни одного круга (никакие буквы `X` не дописываются).
* *Строка на данном шаге:* `MMMCM` + `L` = **`MMMCML`**

#### 4. Индекс `j = 3` (Единицы). Цифра `digit = 4`
* Срабатывает условие `if(digit == 4)`. Это второй особый случай вычитания!
* Код выполняет две строчки:
  ```csharp
  sb.Append(ones[3]);  // Печатаем "ones" текущего разряда единиц -> "I"
  sb.Append(fives[3]); // Печатаем "fives" текущего разряда единиц -> "V"
  ```
* В строку склеивается комбинация **IV** (один перед пятью, то есть 4).
* *Строка на данном шаге:* `MMMCML` + `IV` = **`MMMCMLIV`**

---

## 🏁 3. Резюме для числа 3954

Алгоритм красиво и изящно собрал число из четырех совершенно разных кусков:
1. **`MMM`** (3000) — через тернарный оператор и цикл (блок `else`).
2. **`CM`** (900) — через специальную проверку на девятку (`digit == 9`).
3. **`L`** (50) — через тернарный оператор, который обнулил счетчик цикла, оставив только чистую «пятерку».
4. **`IV`** (4) — через специальную проверку на четверку (`digit == 4`).

Метод успешно возвращает финальный результат: **`MMMCMLIV`**.
